# nallabot 💣

Telegram SMS Bomber Bot — triggers OTP from 9 platforms simultaneously.

## Endpoints
🛍️ Meesho • 🏦 Ram Fincorp • 🚗 Maruti Suzuki • 🏠 NoBroker • 🎫 District.in • 📦 Delhivery • 🎬 BookMyShow • ⚡ Blinkit • 📱 Jio

## Setup
1. Create a bot via [@BotFather](https://t.me/BotFather)
2. Set `BOT_TOKEN` as environment variable on Render
3. Deploy as **Background Worker**

## Run Locally
```bash
pip install -r requirements.txt
# create .env with BOT_TOKEN=your_token
python bot.py
```
